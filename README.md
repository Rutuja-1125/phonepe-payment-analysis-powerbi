# phonepe-payment-analysis-powerbi
Interactive PhonePe payment analysis dashboard built using Microsoft Excel and Power BI to analyze transactions, payment trends, user segments, services, and transaction success rates.

# 📊 Project Overview
This project analyzes PhonePe digital payment data using **Microsoft Excel and Power BI**.
The objective is to understand transaction trends, payment performance, user behavior, service-wise transaction values, and demographic contributions through an interactive business intelligence dashboard.

# 🛠️ Tools & Technologies
- Microsoft Excel
- Power BI

- Data Analysis
- Data Visualization
- Business Intelligence

# 🎯 Project Objectives
- Analyze overall transaction volume and transaction value
- Monitor payment success rate
- Understand user contribution across age segments
- Analyze transaction trends over time
- Compare weekday and weekend usage
- Analyze transaction value across different services
- Identify top users based on transaction value
- Explore payment methods through interactive tooltip analysis

# 🔍 Key Insights
- The dashboard shows a **96% successful transaction rate** within the analyzed dataset.
- Weekday transactions contribute a larger share of overall usage than weekend transactions.
- Loans represent the largest transaction value among the analyzed services.
- The age-segment analysis shows differences in transaction contribution across user groups.

# 💡 Business Questions Explored
1. How many transactions were processed and what was their total value?
2. What is the overall transaction success rate?
3. How does transaction activity change over time?
4. Which age segments contribute the most transactions?
5. Which services generate the highest transaction value?
6. How does weekday usage compare with weekend usage?
7. Who are the top users by transaction value?
